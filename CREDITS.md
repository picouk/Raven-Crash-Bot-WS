## Technologies Used

### Core Frameworks & Libraries

#### Telegraf
- **Description:** Modern Telegram Bot Framework for Node.js
- **Version:** ^4.3.0
- **License:** MIT
- **Website:** https://telegraf.js.org/
- **Usage:** Main framework for Telegram bot functionality

#### Baileys
- **Description:** WhatsApp Web API implementation
- **Repository:** github:fthym7261-sys/WaBails
- **License:** MIT
- **Usage:** WhatsApp integration and session management

#### Express
- **Description:** Fast, unopinionated web framework for Node.js
- **Version:** ^4.21.2
- **License:** MIT
- **Website:** https://expressjs.com/
- **Usage:** Web server functionality
